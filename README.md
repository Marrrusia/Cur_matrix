MatrixWidget

MatrixWidget - это программа, предназначенная для создания, отображения и манипулирования матрицой. Она предоставляет интерфейс для изменения размеров матрицы, просмотра подматриц, сохранения и загрузки данных из файлов, транспонирования, замены элементов, подсветки ячеек и заполнения матрицы случайными значениями.

Возможности:
- Изменение размера матрицы: Возможность задавать количество строк и столбцов матрицы через спинбоксы.
- Просмотр подматрицы: Отображение выбранной части матрицы (подматрицы) в отдельном окне.
- Просмотр всей матрицы: Отображение полной матрицы в табличном виде.
- Сохранение/Загрузка из файла: Сохранение матрицы в текстовый файл и загрузка данных из файла. Поддерживается сохранение как всей матрицы, так и выбранной подматрицы.
- Очистка матрицы: Возможность очистить все поля матрицы.
- Транспонирование матрицы: Создание новой матрицы, в которой строки и столбцы исходной матрицы поменяны местами.
- Замена элементов матрицы: Возможность заменить один элемент матрицы другим.
- Подсветка ячеек: Выделение ячеек матрицы определенным цветом на основе заданных критериев.
- Случайное заполнение матрицы: Заполнение матрицы случайными значениями в заданном диапазоне.

Сборка

Разработка и сборка проекта осуществлялась с использованием следующей конфигурации:

Компилятор: MinGW 8.1.0 (64-bit), C++.

Процесс сборки:
- Откройте файл проекта matrix.pro в среде Qt Creator.
- Инициируйте процесс сборки.
- Исполняемый файл MatrixWidget.exe будет создан в каталоге release или debug в зависимости от выбранной конфигурации сборки.
